# Treehouse — creative direction

Idiom: an architect's design process for a Pacific Northwest craftsman treehouse,
shown as four sheets of the same drawing set.

1. **First lines** — graphite on canary "yellow trace" paper. Lines overshoot corners
   the way hand drafters do. Paper has fiber grain.
2. **Massing** — basswood study model. Pale warm wood, matte, no texture, soft
   daylight. Blocks rise from the platform up via a shader height cutoff.
3. **Detail** — windows, Dutch door, balusters, knee braces, ladder, shingles-as-geometry
   appear in a staggered build, still in basswood.
4. **Finished** — weathered cedar shingles, board-and-batten siding, Douglas-fir timbers,
   oak canopy, warm lamp glow in the windows, low golden-hour sun with long shadows.

UI: a drafting title block (hairline borders, uppercase mono labels, hand-lettered
values), sheet numbers A-101..A-104, a scrubbable timeline.

Banned: dark UI chrome, purple/blue gradients, glow/bloom, glassmorphism, rounded
cards, pill badges, emoji, default grey three.js background.
