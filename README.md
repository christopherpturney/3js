# 3js

Three.js and SVG site visualizations.

| Page | What it is |
|---|---|
| [Treehouse](https://christopherturney.com/3js/) | Four-stage WebGPU animation: sketch, massing, detail, finished |
| [Backyard](https://christopherturney.com/3js/backyard/) | Backyard model at exact dimensions from a SketchUp export ([plan-set style](https://christopherturney.com/3js/backyard/civil.html)) |
| [APCO repair sequence](https://christopherturney.com/3js/Everline/apco/animation-lite.html) | Lightweight SVG animation of a parking-lot repair proposal |
| [APCO site plan](https://christopherturney.com/3js/Everline/apco/) | Draft site layout with the repair placement editor |

Pages embed their data, so each one also opens straight from the file system.
Source imagery (Google aerials, Street View) and the client proposal are kept out of this repo.
